Create a page to add or remove items from backpack.

  1. Create a page with 3 items already in the backpack. (Pen, Book and WaterBottle)
  2. Add a textbox and a button. When the button is clicked, the item in the textbox should be added as a list item.
  3. When a new item is added, there should be a delete button next to it.
  4. When the individual delete button is clicked, the corresponding item should be removed from the list.
  5. The page should be updated with the list.
