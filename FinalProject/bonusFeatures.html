Tic-Tac-Toe Project - Bonus Features

In this project, you will implement the following bonus features to enhance your Tic-Tac-Toe game:

Goal

  • Implement ScoreBoard
  • Highlight Winning Cells

ScoreBoard

  • On the top right, display scores for each player
  • Example: Player X: 3 | Player O: 2

Highlight Winning Cells

  • When a player wins, highlight the three winning cells
  • Use a different background color to indicate the winning cells. Example: Green
